# What if you lived for 1000 years?

Бумажная 2.5D-анимация, около 8 минут. Английский текст, субтитры, оригинальная музыка и звуковые эффекты. Голос автор записывает сам.

## Что внутри

| Путь | Что это |
|---|---|
| `docs/voiceover-script.txt` | Текст для озвучки |
| `docs/storyboard.md` | Раскадровка: единая нить, по 3–5 вариантов на каждую сцену, выбор |
| `subtitles_en.srt` | Английские субтитры, тайминг по словам |
| `src/timeline.py` → `src/timeline.json` | Мастер-таймлайн: время каждого слова (~168 слов/мин) |
| `src/engine.js`, `src/lib.js` | 2.5D-движок: перспективная камера, бумажные слои, тени, DOF, motion blur |
| `src/scenes_a/b/c.js` | 18 сцен |
| `src/audio.py` | Синтез партитуры и SFX (numpy/scipy) → `audio/*.wav` |
| `render.js`, `render_all.sh`, `finalize.sh` | Рендер кадров (Playwright) → MP4 (ffmpeg) |

## Сборка

```bash
python3 src/timeline.py      # таймлайн + субтитры
python3 src/audio.py         # музыка и SFX
J=4 ./render_all.sh          # 1920x1080, 60 fps → build/video_noaudio.mp4
./finalize.sh                # out/what_if_1000_years.mp4 и версия со вшитыми субтитрами
```

Превью в браузере: `src/index.html?t=120` (кадр) или `src/index.html?play&t=120` (воспроизведение).

## Синхронизация с вашей озвучкой

Анимация и субтитры рассчитаны на темп около 168 слов в минуту: каждое слово имеет своё время в `timeline.json`. Синхронизировать можно двумя способами:

1. **Читать в этом темпе.** Включите видео с субтитрами и читайте под них, как с телесуфлёра. Музыка оставляет место для голоса в речевом диапазоне.
2. **Подогнать видео под голос.** Если пришлёте готовую озвучку, времена слов заменяются реальными, и ролик перерендеривается. Тогда все события, переходы и субтитры встанут точно под ваш голос.
